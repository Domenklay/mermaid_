# Дочь двух миров — «Песнь прилива» (Android 0.6)

Кинематографичная визуальная новелла на русском языке с сюжетными развилками, иллюстрациями и сохранениями.

## Скачать APK

Откройте вкладку **Actions** → последний успешный запуск **Build Daughter of Two Worlds APK** → в разделе **Artifacts** скачайте `Doch_dvuh_mirov_v06_debug_APK`. В ZIP будет файл `app-debug.apk`, который устанавливается на Android 7.0 и новее.

## Сборка

Каждый push в `main` автоматически запускает сборку через GitHub Actions. Возможен также ручной запуск `workflow_dispatch`.

В каталоге `story/parts` HTML-код и встроенные иллюстрации разделены на текстовые части из-за ограничений размера передачи. GitHub Actions соединяет их **в правильном порядке** и проверяет SHA-256, затем упаковывает как `app/src/main/assets/index.html`.

Android-проект: Java 17, Gradle 8.9, Android Gradle Plugin 8.7.3, compile SDK 35, min SDK 24. Интернет для игры не требуется. Данные сохраняются локально на устройстве. Не удаляйте приложение перед обновлением без резервной копии данных.
