# Дочь двух миров — главы I и II (Android 0.7)

Офлайн-кинематографичная визуальная новелла на русском языке. **В версии 0.7 добавлена глава II «За гранью волн»**: 23 сюжетные сцены, новые развилки, маяк, человеческий смотритель Илар и последствия выбора, сделанного в первой главе.

## Скачать APK

Откройте [Actions → Build Daughter of Two Worlds APK](https://github.com/Domenklay/mermaid_/actions/workflows/build-apk.yml), выберите последний успешный запуск и скачайте архив **Doch_dvuh_mirov_v07_debug_APK**. Внутри — установочный `app-debug.apk` для Android 7.0+.

## Содержимое

- Глава I «Песнь прилива» (оригинальный сюжет 0.6 сохранён).
- Глава II «За гранью волн»: путь к маяку, встреча с людьми, три разных исхода кульминации.
- События главы II реагируют на выборы первой главы (Невин, Мира, Кай, Нерида и осколок печати).
- Автосохранение, три ручных слота, история реплик, галерея, настройки текста и фоновых звуков.
- Во второй главе временно повторно используются существующие иллюстрации. Новых изображений в 0.7 пока нет.
- Нет сетевых запросов: игра работает офлайн.

## Сохранения и обновление

Внутренний ключ данных сохранений **не изменён** по сравнению с 0.6, при *штатном* обновлении прогресс продолжится. Однако APK из GitHub Actions — отладочные: разные сборки могут быть подписаны разными ключами. **Если Android сообщает о конфликте подписи, не удаляйте установленную игру без резервной копии: это может стереть локальные сохранения.** Для гарантированно бесшовных обновлений нужен один постоянный закрытый ключ подписи.

## Разработка

Исходная версия 0.6 разделена на части в `story/parts`. CI восстанавливает HTML и проверяет его SHA-256, затем добавляет `story/chapter2_v07.js` в ту же офлайн-страницу перед запуском движка. Версия Android: Java 17, Gradle 8.9, AGP 8.7.3, SDK 35.
